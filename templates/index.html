What's Under the Hood

Every panel maps directly to a live endpoint — no mock data, no build step.

Stage Classifier POST a crop photo to /predict — the inference pipeline returns the current growth stage.
Timed Automaton Sequences are verified against transition and dwell-time rules before anything is accepted.
Dwell-Time Bounds Per-stage minimum and maximum durations catch premature moves and abnormal stagnation.
Scenario Simulator Five canned lifecycles exercise skip, backward, premature, stagnation and healthy paths.
Session Control One call to /reset clears the growth log and rewinds the model cursor.
Zero-Build API Every panel is server-rendered by Flask + Jinja over plain HTTP — inspectable end to end.
